# EverTale — প্রজেক্ট প্রিভিউ

তিনটি আলাদা পর্বের জন্য `youtube-porbo-1` থেকে `youtube-porbo-3` এবং `facebook-porbo-1` থেকে `facebook-porbo-3` কম্পোজিশন রয়েছে। প্রতিটি 1080 × 1920, ৩০ fps, এবং নিজস্ব নির্বাচিত কণ্ঠের অডিও ব্যবহার করে। ছয়টি `cover-...` কম্পোজিশন প্রিভিউ করার জন্য রয়েছে। Facebook ও YouTube ভার্সনে টেক্সট অবস্থান ও কভারের উপস্থাপনা আলাদা; পূর্ণাঙ্গ প্ল্যাটফর্মভিত্তিক সম্পাদনার আরও উন্নতি করা যেতে পারে।

## প্রিভিউ

Node.js ইনস্টল করা থাকলে প্রজেক্ট ফোল্ডারে:

```bash
npm install
npm run preview
```

ব্রাউজারে দেখানো ঠিকানাটি খুলে পর্ব ও প্ল্যাটফর্ম বেছে প্লে করুন। Remotion Studio-তে সম্পাদনা করতে `npm run start` চালান।

Remotion Studio-তে সংশ্লিষ্ট ভিডিও বা কভার বেছে প্লে করুন। সিনের টেক্সট ও চরিত্রের নকশা `src/video.tsx`-এ এবং ভিডিওর দৈর্ঘ্য `src/root.tsx`-এ আছে। কভারের PNG চাইলে অনুমোদনের আগে শুধুমাত্র স্থির ছবি হিসেবে বের করা যায়, যেমন:

```bash
npx remotion still src/index.ts cover-facebook-1 facebook-cover-1.png
```

চূড়ান্ত ভিডিও রেন্ডার ব্যবহারকারীর স্পষ্ট অনুমোদনের পরেই করতে হবে। উদাহরণ (একইভাবে সব ছয়টি composition রেন্ডার করুন):

```bash
npx remotion render src/index.ts youtube-porbo-1 youtube-porbo-1.mp4
npx remotion render src/index.ts facebook-porbo-1 facebook-porbo-1.mp4
```

## প্রিভিউ সীমাবদ্ধতা

- দৃশ্য পরিবর্তন ও ওভারলে টেক্সটের সময় আনুমানিক; ভয়েসের সঙ্গে শুনে যাচাই ও পরিমার্জন করা প্রয়োজন। এখনো শব্দ-নির্ভুল SRT তৈরি হয়নি।
- স্ক্রিপ্টে কেবল বর্ণনা আছে, চরিত্রের সংলাপ নেই; তাই কোনো চরিত্রের সংলাপ বা লিপ-সিঙ্ক কল্পনা করে যোগ করা হয়নি।
- মিউজিক বা সাউন্ড ইফেক্ট যোগ করা হয়নি; ব্যবহারযোগ্য স্বত্ব-নিশ্চিত অডিও পেলে যোগ করা যাবে।
- Hind Siliguri ফন্ট অফলাইনে নির্ভরযোগ্যভাবে লোড করতে npm-এর `@fontsource/hind-siliguri` ব্যবহার করা হয়েছে।
- YouTube ও Facebook-এর ইন্টারফেস ও কভার ক্রপ ডিভাইসভেদে বদলাতে পারে; আপলোডের সময় যাচাই করতে হবে।
